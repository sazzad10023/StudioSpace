# StudioSpace
### Peer-to-Peer Creative Workspace & Production Studio Sharing Platform

A modern platform where creators can discover, explore, and book
creative studios for photography, filmmaking, podcasting, music,
and other creative projects.


## Features

- Browse and explore creative studio spaces.
- Search and filter studios by category and location.
- View detailed studio information and amenities.
- User authentication with email and Google login.
- Add, update, and delete personal studio listings.
- Book available studio slots.
- Manage bookings and booking status.
- Responsive design for mobile, tablet, and desktop.

## Technology Stack

### Frontend
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Shadcn UI

### Backend
- Node.js
- Express.js
- TypeScript
- MongoDB
- Mongoose

### Authentication
- Better Auth
- JWT




## Key Features

- **Studio Discovery:** Explore creative studios with category-based filtering and search functionality.
- **User Authentication:** Secure registration and login with Google authentication.
- **Studio Management:** Add, update, and delete your own studio listings.
- **Online Booking System:** Book creative spaces and manage reservations with booking status tracking.
- **Responsive Design:** Enjoy a clean and user-friendly experience across desktop, tablet, and mobile devices.
